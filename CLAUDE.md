## Git workflow (owner's standing instruction)

- Commit and push directly to `main`. Do not create branches or pull requests unless the owner asks for one.
- Before committing, pull the latest `main` so the push doesn't conflict with changes synced from Obsidian (Obsidian Git auto-commits and pushes every 10 minutes).
- Keep commit messages short and say what changed.
- Never force-push to `main`.

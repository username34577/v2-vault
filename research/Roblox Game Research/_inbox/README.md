# Inbox

Drop gameplay recordings, screenshots and reference images here (from Obsidian on your phone or from your PC). The next Claude Code session files them automatically into `Media/<Game>/`; see [[Roblox Game Research]].

Name the game one of three ways: a subfolder (`Grow a Garden/shop.png`), a prefix (`Grow a Garden - shop.png`), or the game's name or alias anywhere in the file name. Anything else goes to `Media/_Unsorted/`.

Videos: `.mp4 .mov .webm .mkv .m4v .avi`. Images: `.png .jpg .jpeg .gif .webp .bmp .heic`. Other files stay here and are reported. Keep videos under about 95 MB (bigger files are kept out of git).

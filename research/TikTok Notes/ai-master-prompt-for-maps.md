# Make good maps: master prompt from another AI

**Creator:** @jacobunfiltered · **Length:** 68s · [Watch on TikTok](https://www.tiktok.com/@jacobunfiltered/video/7702316378866421023)
**Theme:** Building / maps · Back to [[TikTok Notes]]

## Summary
Don't type map prompts yourself. Have another AI write a detailed master prompt, then paste it into Claude.

## Key points
- Tell the helper AI exactly how high-fidelity you want it: realistic terrain, high-quality models, no free models, fog, lighting, etc.
- Paste the generated master prompt into Claude to build the map.
- He says he built a good-looking map in under a day this way.

## Worth it?
Useful idea. Claude can also write that master prompt itself, so a second AI is optional.

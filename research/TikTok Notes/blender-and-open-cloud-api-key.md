# Claude + Blender, auto-import with an API key

**Creator:** @cuhfilme · **Length:** 110s · [Watch on TikTok](https://www.tiktok.com/@cuhfilme/video/7691100637794192671)
**Theme:** Building / maps · Back to [[TikTok Notes]]

## Summary
Uses Claude with Blender to make models, then lets Claude upload them to Roblox itself using an Open Cloud API key.

## Key points
- Creator Dashboard → All tools → API keys → Create API key (personal key, not group).
- Permissions: Assets read + write, Asset permissions write. Optional: developer products, game passes.
- Store the key in an environment variable, never pasted in your code.
- Tell Claude where the key is and to import models itself.

## Worth it?
Useful later. Treat the key like a password, give it only the permissions it needs, and he uses an alt account to be safe.

# Game review: 1M visits, 23 players left

**Creator:** @captainamado · **Length:** 86s · [Watch on TikTok](https://www.tiktok.com/@captainamado/video/7701614446174588174)
**Theme:** Game design · Back to [[TikTok Notes]]

## Summary
Review of a sports game that got traffic but lost everyone. The fix is in the first minutes.

## Key points
- Set up Roblox Funnel analytics so you can see where players drop off.
- Check thumbnail CTR.
- Test on mobile; lots of players are on phones.
- Don't lock players out of everything during the tutorial. Too much tutorial text drives people away.

## Worth it?
Very useful. This is exactly the mistake to avoid in a first game.

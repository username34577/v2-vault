# Obsidian + Claude Code agent: structure

**Creator:** @jaredrhod · **Length:** 619s · [Watch on TikTok](https://www.tiktok.com/@jaredrhod/video/7652419341723405581)
**Theme:** Workflow · Back to [[TikTok Notes]]

## Summary
Ten-minute walkthrough. Key is organization plus instructions in the vault, not complex agent loops.

## Key points
- Move Claude's memory files into the Obsidian vault and consolidate them (he went from 107 files to 17).
- Each folder gets a master note with the same name that wiki-links every other note in the folder.
- A 'jobs' folder holds step-by-step instructions for repeated tasks, each with its own master note.
- Claude reads one master note and follows the links to get full context.
- Sync the vault to GitHub so everything is backed up.

## Worth it?
Best workflow video in the batch. Apply it: give your game its own folder with a master note.

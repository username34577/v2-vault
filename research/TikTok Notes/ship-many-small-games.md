# Ship 5–10 small games, keep the winner

**Creator:** @skumstudio · **Length:** 53s · [Watch on TikTok](https://www.tiktok.com/@skumstudio/video/7703245348357049614)
**Theme:** Ideas / market · Back to [[TikTok Notes]]

## Summary
Make several quick games with a basic core loop each, run a cheap ad on each, and only keep working on the one that gets traction.

## Key points
- A few hours each: core loop and basic functions only.
- One ad per game with 4–5 thumbnails.
- Keep the one that holds 25–30+ CCU or makes a few hundred to 1,000 Robux a day.
- Don't sink 3 weeks into one game before testing it.

## Worth it?
The idea of testing fast is smart. Low-effort games still need to be fun, or ads just waste Robux.

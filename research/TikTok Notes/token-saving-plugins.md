# 3 plugins to save Claude Code tokens

**Creator:** @jackroberts____ · **Length:** 34s · [Watch on TikTok](https://www.tiktok.com/@jackroberts____/video/7705445733201399072)
**Theme:** Tools · Back to [[TikTok Notes]]

## Summary
Tools to make Claude Code use fewer tokens.

## Key points
- Ponytail: trims extra code (github.com/DietrichGebert/ponytail).
- Graphify: makes a map of your project so Claude reads the map instead of every file (github.com/Graphify-Labs/graphify).
- OmniRoute: switches to a free model when you hit your Claude limit (github.com/cheaper-inference/OmniRoute).

## Worth it?
Could help if you hit limits. Check each repo before installing, since third-party plugins run on your machine.

# Make good UI with reference images

**Creator:** @palm_dev · **Length:** 60s · [Watch on TikTok](https://www.tiktok.com/@palm_dev/video/7684777669875027231)
**Theme:** UI · Back to [[TikTok Notes]]

## Summary
Bad AI-made UI comes from vague prompts ("make it cooler") or overcomplicating it. Feed the AI real reference images instead.

## Key points
- Screenshot UI from games you like, say exactly what you like about it, and tell the AI to use it as a reference and theme it to your game.
- Or: send a normal chat AI a picture of your current UI plus your game's theme, get back a mockup image, then give that image to your coding agent to build.
- Tweak from there. Good references and a clear description beat long prompts.

Solid, easy to apply.

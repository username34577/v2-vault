# 3 Studio plugins for UI designers

**Creator:** @uglyydev · **Length:** 33s · 122K plays · [Watch](https://www.tiktok.com/@uglyydev/video/7694650082246937878) · Back to [[TikTok Notes]]

| Plugin | What he says | Checked |
|---|---|---|
| **AutoScale Lite** | Scales and positions UI so it works on PC and mobile. | **Verified.** Free plugin by ZacBytes (DevForum since 2018): converts Size/Position between Scale and Offset and adds `UIAspectRatioConstraint`. A paid Plus version auto-converts and auto-anchors (50 Robux). |
| **UI+** | Speeds up UI design. | **Unverified.** No plugin by that exact name found. Several similar ones exist (UI Designer Pro, Interface Tools, Sketch, FrameZero). Don't install a lookalike from a Discord link without checking the Creator Store page and author. |
| **2D Emitter** | Particle effects on UI. | **Verified.** Several exist: Synitx's open-source "2D Emitter", and the "Emitter2D" plugin + module that converts a 3D `ParticleEmitter` to UI particles. |

He links the plugins only through his Discord. Install from the **Creator Store** by name and check the author instead.

## How it fits
`roblox-ui-builder` / `lihfolk-ui` already build scale-based UI in code, so AutoScale is mainly useful when you hand-edit UI in Studio. UI particles fit "juice" on buttons and rewards (`47 Game Feel and Juice`); budget them on mobile.

## Worth it?
Small but useful. No install made.
